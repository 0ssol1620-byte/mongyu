# R105 다국어(한국어/영어) 구조

R105 빌드(`MONGYU_UI_EDITION===true`)에서만 켜져요. 다른 릴리스는 한국어 그대로예요. 모듈은 `web/src/i18n.js`(런타임), `i18n-ko.js`, `i18n-en.js`예요.

## 언어 고르는 순서
1. 저장된 선택(`mongyu.lang`, `_MongyuStore`가 있으면 그쪽, 없으면 `localStorage`. 실패해도 조용히 넘어가요)
2. `navigator.languages`의 첫 항목이 `ko`로 시작하면 `ko`, 다른 언어면 `en`
3. 아무것도 없으면 `en`

`<html lang>`은 고른 언어로 바뀌어요. 설정 창의 "언어 / Language" 줄(`#langSwitch`)에서 바꾸면 바로 적용돼요.

## API (`MongyuI18n`)
| 함수 | 설명 |
| --- | --- |
| `t(key, vars)` | `{name}` 자리 채우기. 현재 언어 → 한국어 → 영어 순으로 찾고, 없으면 키를 돌려줘요 |
| `plural(key, n, vars)` | 표는 `{one, other}`(필요하면 `zero`). `Intl.PluralRules` 사용, `{n}` 자동 |
| `register(lang, table, {phrases, patterns})` | 표 등록. 뒤의 객체는 레거시 번역기용 |
| `lang()` / `setLang(l)` | 현재 언어 / 바꾸기(저장, `<html lang>`, 번역기 켜고 끄기, `onChange` 알림) |
| `onChange(fn)` | 언어가 바뀔 때 호출. 해제 함수를 돌려줘요 |
| `tr(koString)` | 한국어 문장을 현재 언어로. 번역이 없으면 그대로 돌려줘요. 캔버스·JS에서 써요 |
| `translate(ko)` | `tr`와 같지만 못 찾으면 `null` |
| `translateTree(node)` / `restoreTree(node)` | 한 번에 번역 / 원래대로 |
| `ensureSwitch()` | 설정 창에 언어 줄을 넣어요(이미 있으면 그대로) |
| `stats()` | 옵저버 호출 수, 처리 노드 수, 누적 ms |

새 문구는 키로 적어요(`i18n-ko.js`와 `i18n-en.js`에 같은 키). 예: `hud.shards` → `빛 {a} / {b}` / `Shards {a} / {b}`.

## 레거시 번역기 (소스를 안 고치고 영어로 보여 주는 다리)
소스 곳곳에 박힌 한국어를 영어 모드에서만 바꿔요.
- **대상:** 텍스트 노드와 `aria-label`, `title`, `placeholder`, `alt`. `<script>`, `<style>`와 `translate="no"`인 곳은 건드리지 않아요. `<canvas>`는 안의 글자는 건드리지 않고 `aria-label`만 번역해요.
- **사전:** `i18n-en.js`의 `phrases`(글자 그대로 일치)와 `patterns`(정규식, `$1` 캡처, `$t1`은 캡처를 다시 번역). 함수형 치환도 돼요.
- **문장 쪼개기:** 통째로 못 찾으면 ` · `, 줄바꿈, ` / `, 문장 끝(`.!?`)으로 나눠 각 조각을 번역해요. **모든 조각이 번역될 때만** 적용하고, 하나라도 못 찾으면 그 문구는 한국어로 남겨요(반쪽짜리 영어를 안 만들려고요).
- **가볍게:** `MutationObserver` 하나로 바뀐 노드만 처리해요. 이미 번역한 노드는 건너뛰고(WeakMap), 한국어 모드에서는 옵저버를 끊어요. 결과는 캐시해요.
- **되돌리기:** 원래 한국어를 WeakMap에 두고 한국어로 바꾸면 복원해요. 앱이 글자를 다시 쓰면 다시 번역해요.
- **캔버스:** `fillText`/`strokeText`/`measureText`에 한 겹을 씌워서 영어 모드의 한국어 리터럴을 `tr()`로 바꿔요.
- **이야기 타자 효과:** 글자마다 `span.tw-c`로 쓰는 줄은 영어 모드에서 통째로 한 글자 노드로 바꿔요. 영어 모드에서는 타자 효과 없이 한 번에 보여요(복원하면 원래 span이 돌아와요).

## 아직 번역하지 않은 것
`content.js` 원작 모드 문구, 100칸 카탈로그와 이야기 장면(`restoration-catalog.js`, `restoration-story-graph.js`), 긴 접근성 설명 일부. 한국어를 다듬은 뒤 마지막 문구 작업에서 `t()` 키로 옮겨요. 그때까지는 한국어로 남아요.
