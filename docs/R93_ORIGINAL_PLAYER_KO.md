# R93 원작 파일 실행 경로와 검증

R92의 자체 캐릭터·녹음곡·각색 대사를 수정하는 방식으로는 ‘원작과 동일’이라는 목표를 충족할 수 없었다. R93은 그 엔진을 APK에서 제외하고, 사용자가 보유한 놈3 KTF ZIP/JAR의 원본 실행 코드와 리소스를 직접 실행한다. **상용 원작 파일은 APK·소스·공개 검사 산출물에 포함하지 않는다. 최초 실행 시 보유한 파일을 선택해야 한다.** 파일과 저장은 기기 안에 보관하며 서버로 전송하지 않는다.

## 콘텐츠와 입력

캐릭터·포즈·대사·스토리 분기·장애물·배경·아이템·카메라·스킨 조건은 선택한 원본 프로그램과 리소스가 결정한다. R92의 벡터 그림·대체 녹음·수집 조건 재해석을 사용하지 않는다. 원본을 각색해 완전히 같다고 주장하는 방식에서 실행 경로 자체를 바꿨다. 모든 콘텐츠의 연속 완주를 검증했다는 뜻은 아니다.

원본 화면은 240×320 비율로 화면 안에 맞춘다. 길쭉한 최신 화면에 맞추려고 원작 그림을 늘리거나 HUD를 자르거나 카메라를 새로 확대하지 않는다. 탭은 OK 입력이며 취소·방향·확인·좌우 소프트키·숫자·별표·우물정 키를 제공한다. 원작 수집판의 별표 도움말과 우물정 스킨 입력도 전달한다. 키패드를 열면 화면 공간을 따로 확보한다. 일시정지·앱 전환은 입력을 놓고 엔진 틱과 오디오를 중단하며, 명시적으로 재개한다.

## 실행기와 소리·속도의 한계

[wie](https://github.com/Jun025/wie) 공개 실행기를 소스 커밋 `1ca15ebf5a3ebc691a680a7854e99a32e75d46f4`에 대응하는 아티팩트로 고정했다. WASM SHA-256은 `a4a32d289c2281239d2d4e9c00c065d10203fe151969a6f324761e4e3a38ecdf`이다. MIT·Apache 2.0·Neo둥근모 OFL 고지를 앱에 포함한다. 상용 게임 파일은 실행기와 별개다.

음표·리듬·PCM 효과음은 가져온 원본 MMF가 생성한다. 현재 MIDI 합성기는 옛 휴대폰의 Yamaha 칩 음색을 동일하게 재현하지 않는다. 따라서 원본 음악 데이터를 실행해도 실기와 같은 음색이라고 할 수 없다. GeneralUser 사운드폰트와 R92의 작곡가 녹음곡은 포함하지 않는다.

설정 속도는 1배속이지만 실제 달성 속도는 기기와 구간에 따라 떨어진다. 브라우저의 개별 구간에서는 약 0.7655, 0.89, 0.9195배가 기록됐다. 최종 Android 에뮬레이터 검사 구간은 약 **0.6420배**였다. 서로 다른 환경·구간의 수치를 성능 개선 비교로 취급하지 않는다. 이 버전은 끊김이 모두 해결됐다거나 원작 실기 속도를 보장하는 완성판이 아니다.

같은 호스트에서 표시 프레임당 틱을 제한적으로 한 번 더 호출하는 대안도 비교했다. 달성 속도 중앙값이 약 0.8345→0.8321로 개선되지 않아 채택하지 않았다. 게임 시간이나 원본 프레임을 임의로 가속해 맞추지 않았다. 근거는 `evidence/r93-scheduling-experiment.json`에 남긴다.

옛 통신사 서버·전화·진동·특정 기기 API, 원작 모든 버전의 동등성, 100개 수집 연속 완주, 모든 포즈·분기·맵의 실기 대조는 미확인이다. 별도 확보한 QA 자료는 제삼자 KTF 후보로 공식 배포본 인증이 되지 않았으며, JAR 지문은 `aeadd87840c7b3f1f06548489406dbc0bf833b41de9cdfa3eaf741e832a213c2`이다. 원본 실행 경로를 확보한 것과 완전 동일 복구를 검증한 것을 구분한다.

## 파일과 기록

최대 입력 16MiB, 풀린 총 크기 64MiB·512개 항목, 모든 항목 CRC·경로·중복·필수 리소스를 검사한 뒤 보관한다. JAR 단독 입력에는 실행용 컨테이너 정보만 덧붙이며 JAR의 코드·그림·음악·문장을 바꾸지 않는다. 완전한 ZIP의 기존 원본 저장도 읽는다.

Android 시스템 파일 선택기로 파일을 앱 내부 저장소에 복사하고 해시 확인 뒤 채택한다. 인터넷·광범위 저장소 권한은 추가하지 않는다. 잘못된 대체 파일은 이전 파일을 덮지 않는다. 원본 코드가 만든 불투명한 저장 바이트를 파일 지문별 저널로 보관하며, 이전 유효 기록을 백업한다. 손상 기록과 미래 형식을 조용히 덮어쓰지 않는다. 기존 몽유 기록도 삭제하거나 원작 수집 진척으로 변환하지 않는다.

## 확인한 범위

- 컨테이너·CRC·경로·파일 거부·저장 저널·일시정지·종료 검사 **8개 통과**. 현재 검사는 `python3 scripts/test.py`, 과거 각색 엔진 검사는 `python3 scripts/test-legacy-r92.py`로 분리한다.
- 실제 원작 후보 ZIP와 JAR 단독을 브라우저에서 각각 불러와 정상 입력·음표/PCM 출력·원본 저장·재실행·잘못된 교체 거부를 확인했다. 준비 화면에서도 원본 파일 ID를 유지한다. 네 화면 크기의 비율 보존과 세 화면 크기의 방향/숫자 키 배치·화면 비가림을 검사했다.
- [최종 Android Actions 검사](https://github.com/0ssol1620-byte/mongyu/actions/runs/43718973589)는 커밋 `4c47a33ec6e97f150f4f7c7b60d0c19b8db0949b`, API 35 x86_64 Pixel 6/SwiftShader, WebView 124에서 통과했다. 실제 시스템 파일 선택기, 원본 리소스 106개·음악 파일 17개, 정상 터치 입력, MIDI/PCM 메시지, 원본 저장, 일시정지, 뒤로/백그라운드, APK 업데이트 후 파일·저장 보존, 렌더러 장애 후 복구를 검사했다.
- 업데이트 검사는 같은 R93 호스트의 버전 코드 92→93에 임시 CI 인증서를 사용했다. 실제 이전 R92 엔진에서의 업데이트나 물리 휴대폰 검증과 구분한다. QA 원본 후보의 기존 10/100 저장만 `p/`에서 제외해 새 게임이 실제로 저장하게 했으며 실행 코드·리소스는 바꾸지 않았다. 제품은 사용자가 가져온 기존 저장을 제거하지 않는다.
- 에뮬레이터 첫 부팅 때 발생한 Quickstep 런처 ANR은 명시적으로 식별해 닫고 환경 문제로 기록했다. 게임 ANR을 닫아 통과시키지 않는다. 원작 입력과 개인 분석 캡처는 공개하지 않고 검사 후 임시 입력을 삭제한다.
- 배포 APK는 **검사한 Actions의 unsigned 산출물 자체**에 기존 미리보기 인증서로 서명했다. 서명 외 16개 ZIP 항목이 동일함을 확인했다. 자산 12개 해시·인증서·버전·권한 없음·ZIP 정렬을 검증했다. 최종 미리보기 인증서로 서명한 APK를 물리 기기에 직접 설치한 검사는 하지 않았다.

공개 근거는 `evidence/r93-android.json`, `r93-original-browser.json`, `r93-original-jar-browser.json`, `r93-input-layout.json`, `r93-signed-apk.json`이다. 게임 파일·원본 화면·음표 이벤트를 포함하지 않는다. R93은 Android 8.0 이상용 미리보기이며 실제 광고·결제는 없다. 원작 파일의 배포 권한 확보와 기기별 완주·성능 검증 없이 상용 출시 완료로 표시하지 않는다.
