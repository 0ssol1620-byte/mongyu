# R100 시각 연출 연구

| 연구에서 확인한 내용 | 몽유에 옮긴 요소 |
| --- | --- |
| Bressloff 외 연구는 Klüver의 격자, 거미줄, 터널, 나선 분류를 바탕으로 반복 형태의 대칭성을 분석했다. | 로비의 중심으로 접히는 색 띠에는 나선과 터널을, 꿈 지도의 기억 사이에는 엇갈리는 격자를 적용했다. [연구 원문](https://doi.org/10.1098/rstb.2000.0769) |
| Carhart-Harris 외 연구는 LSD 경험에서 시각 환각 평정과 일차 시각 피질의 기능적 연결 변화가 연관되는 모습을 관찰했다. | 화면을 하나의 움직이는 공간으로 읽도록 로비의 윤곽을 여러 층으로 포갠다. 어긋나게 그린 청록색과 자홍색 윤곽은 천천히 이동하고 넓어진다. [연구 원문](https://doi.org/10.1073/pnas.1518377113) |

## 화면별 적용

- 로비에서는 새로 만든 방사형 배경과 살짝 어긋난 윤곽이 주인공과 빛 조각을 둘러싼다. 세로에서는 터널이 전경을 감싸고, 가로에서는 제목과 버튼을 왼쪽에 두고 장면을 오른쪽에 펼친다.
- 꿈 지도와 옷장에서는 색 띠를 뒤에 두고, 기억 선택과 장착 상태는 테두리와 글자로 읽을 수 있게 했다. 꿈 지도의 설명 카드는 내용 높이에 맞춰 배경이 드러난다.
- 이야기와 일지에서는 말풍선과 본문에 불투명한 바탕을 대고 배경을 낮췄다. 설정, 일시정지, 결과의 실행 버튼은 로비와 같은 색과 형태를 공유한다.
- 첫 코스의 배경에는 엷은 색 윤곽을 넣었다. 발판·장애물·빛 조각은 배경과 구분되는 선명한 색으로 그린다.

설정의 **꿈의 강도**에서 고요·균형·강렬을 고를 수 있다. **모션 줄이기**를 사용하면 로비의 윤곽과 대기 애니메이션을 정지한다. 새 화면에 빠르게 반짝이는 광원은 사용하지 않았다. [WCAG 애니메이션 기준](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html) · [WCAG 섬광 기준](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html)


## 검증

- 390×844와 844×390 화면에서 로비, 꿈 지도, 옷장, 이야기 일지, 설정, 이야기 장면, 일시정지, 결과를 열었다. 세 가지 강도 설정과 모션 줄이기, 터치 완주와 다음 기억 이동도 확인했다. [화면 검증](../evidence/r100-theme.json)
- iPhone 크기의 WebKit에서 코스 완주와 세 구간 음악, 새로고침 뒤 진행 저장을 확인했다. GitHub Pages의 공개 HTML과 검증한 Android APK의 게임 파일이 일치했다. [브라우저 검사](../evidence/r100-webkit.json) · [공개 파일 대조](../evidence/r100-web-release.json)
