# 몽유 R95 플레이 검수

| 발견 | 수정 | 확인 방법 |
| --- | --- | --- |
| 첫 이야기를 읽은 뒤 지도에서 시작 버튼을 한 번 더 찾아야 했다. | ‘첫 달리기 시작’에서 게임을 연다. 이야기 메뉴에서 읽는 경우 기존 지도 경로를 사용한다. | 새 기록에서 실제 터치로 진행 |
| 첫 연습에서 충돌할 때마다 시간이 1,000틱으로 늘고 연속 충돌이 발생했다. | 첫 연습에만 적용하는 보호 시간을 추가했다. 부딪히면 짧은 조작 힌트를 표시하고 남은 시간은 계속 흐른다. | 일반 터치 도중 충돌을 겪고 15~17초에 완주 |
| 달리는 동안 현재 점수의 의미와 남은 기회를 알아보기 어려웠다. | 점수와 기회를 분리하고 점수 목표형 스테이지에 진행 표기를 추가했다. 시작 카운트다운에 안내를 붙였다. | 다음 기억의 300점 목표와 일시정지 UI 확인 |
| 획득한 기억을 처리하고 다음 기억으로 가려면 지도를 거쳐야 했다. 다시 달리기에서도 지도가 열릴 수 있었다. | 결과에서 다음 기억 또는 다시 달리기를 누르면 획득을 먼저 반영하고 해당 경로를 연다. 설정이나 시간 선택이 필요한 기억은 지도를 연다. | 첫 달리기 완료, 다음 기억 진입, 재시작, 재실행 후 획득 유지 |
| 일부 정상 결과에는 연속 기록 값이 없어 최고 점수 저장이 실패했다. | 해당 엔진의 결과에서 최고 점수와 완주 횟수를 저장하도록 수정하고 실제 갱신 시 새 최고 기록을 표시한다. | 실제 결과와 재실행 후 저장 확인 |
| 밝은 배경에서 장애물과 캐릭터가 묻히고 어두운 맵에서는 발판 가장자리가 흐렸다. | 배경 채도를 눌러 두고 장애물의 밝은 중심, 발판 가장자리, 캐릭터 스카프로 읽는 순서를 만들었다. | 세로·가로 화면 확인. 격리된 74개 물리 스테이지의 지상·모서리 관절 표본 검사 |
| 매 프레임 곡 크레딧과 파형을 만들고 정지 화면도 반복해서 그렸다. | 플레이와 설정의 음악 정보 조회를 줄이고 정지 화면 재그리기를 제한했다. 배경용 캔버스를 재사용하면서 색 변화는 캐시 키에 포함한다. | 동일한 Chromium 화면 크기·CPU 제한의 비교 측정, Android 복귀와 렌더러 복구 검사 |

첫 달리기에서 충돌이 시간을 늘리던 문제는 일반 터치를 46초 이상 주고도 끝나지 않은 실행에서 발견했다. 변경 후 정상 입력으로 기억 획득과 다음 기억 진입, 최고 기록 표시, 재시작과 새로고침 후 획득 보존을 확인했다. 세 번째 기억에서 기회를 모두 잃은 뒤 결과 화면의 재도전으로 같은 단계가 다시 시작되는 것도 확인했다. 테스트는 모의 진행도를 기록하지 않는다. 접촉 검사는 74개 스테이지를 각각 열어 지상 1,867개와 모서리 365개 표본에서 다리 중심선이 발판 내부와 겹치는지 검사했다. 해당 표본의 교차는 0건이었다. 제한된 표본이며 모든 공중 포즈를 검사한 값은 아니다.

작은 세로 화면과 가로 화면에서 꿈 지도 10쪽의 항목 100개, 시작 시 잠긴 이야기·의상, 설정 버튼을 실제 터치로 확인했다. 초기 기록에서 잠긴 항목을 시작하거나 획득하지 않음을 확인했다.

브라우저 성능은 화면 폭 390, 높이 844, DPR 2, CPU 4배 제한으로 확인했다. 같은 환경에서 재생을 반복해도 스케줄링과 입력 시점에 따라 긴 프레임이 달라진다. R95의 작업 중 비교에서는 95백분위 프레임 시간이 줄었지만 중앙값은 느려졌다. 이 수치로 실제 휴대폰에서 프레임 개선이나 끊김 해결을 보장할 수 없다.

현재 배포는 설치 직후 오프라인으로 플레이하는 R95 미리보기다. 장시간 실제 Android 기기 플레이, 100개 기억 연속 완주, 반복 플레이율과 이탈률은 이번 검증 범위 밖이다. 원작 게임의 캐릭터·음원·스테이지 복제를 이 변경의 목표로 삼지 않았다. 최고 기록과 다음 목표는 플레이의 선택지를 보여주는 방식이며 실제 광고·결제는 활성화하지 않았다.

[최종 Android Actions 검사](https://github.com/0ssol1620-byte/mongyu/actions/runs/44435055899)에서 R94 설치 후 R95 업데이트, 저장된 의상 로드, 첫 달리기, 전체 화면과 터치, 음원 재생, 일시정지와 앱 복귀, 재실행 및 렌더러 복구가 통과했다. API 35 에뮬레이터와 임시 검사 인증서를 사용했다. 배포에는 해당 unsigned APK에 기존 미리보기 인증서로 서명했다. 서명과 무관한 5개 ZIP 항목은 검사한 파일과 동일하다. 세부 근거는 `evidence/r95-*`에 있다.
