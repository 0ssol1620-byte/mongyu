# R85 카메라와 개 동행

실제 플레이의 개 위치가 항상 null이어서 이야기에서 만난 개가 달리기 중에는 보이지 않았습니다. 고정 배율 카메라에도 상황에 따른 확대·축소가 없었습니다.

## 변경

- 개 동행: native resource 1의 7개 포즈 기록 중 다음에 덮어쓸 기록을 읽습니다. 별도 충돌체나 임의의 따라가기 AI를 만들지 않습니다. 22번째 만남 이후 개 구간에서만 표시하고, 기록이 활성화되기 전과 인물 교체 후에는 표시하지 않습니다.
- 위치와 점프는 기록된 좌표·방향·상태를 사용하고, 화면 표시만 프레임 사이에서 보간합니다. 원래 스프라이트 대신 몽유용 얇은 실루엣과 네 다리 동작을 그립니다.
- 카메라는 직선에서 최대 1.09배로 당기고, 코너 접근과 공중에서는 기본 배율 쪽으로 풀립니다. 배율만 약 0.45초의 시간 상수로 완화하며 위치에는 추가 추적 지연을 넣지 않습니다.
- 기본 화면 채움 배율 아래로 축소하지 않습니다. 두 인물이 화면에 함께 들어갈 수 있을 때 개의 귀와 꼬리도 여백 안으로 잡습니다. 주인공 발은 화면 안의 안전 범위에 유지합니다.
- 일시정지에서는 배율이 멈춥니다. 움직임 줄이기 설정에서는 동적 확대를 사용하지 않습니다. 보스는 전체 경기장 구도를 유지합니다.
- native 엔진, 충돌, 입력, 점수, RNG 및 과금 상태는 이 변경에서 수정하지 않습니다. R84 스냅샷 복사 최적화와 기존 저장 키를 유지합니다.

## 확인과 한계

131개 웹 검사 중 130개 통과, 외부 어댑터 1개 생략. Android 콜백 검사 5개 통과. 동행 검사는 실제 23번 슬롯을 정상 입력으로 180회 업데이트하여 네 방향의 과거 포즈, 지연된 회전, native 의미 렌더 명령과의 좌표 일치, 표시 후 시뮬레이션 불변을 확인합니다. 확대 검사에서는 직선/코너 배율 변화, 일시정지, 움직임 줄이기, 세 화면 비율의 모든 1도 회전각을 확인합니다.

Chromium의 최종 번들로 네 방향의 동행 화면, 오프라인 실행, 화면 크기 변경, 일시정지를 확인했습니다. 최종 4배 CPU 제한 측정은 120프레임에서 중앙 프레임 간격 16.7ms, 95백분위 31.8ms였습니다. 이는 데스크톱 브라우저 측정이며 휴대폰 프레임률을 보증하지 않습니다. 자료는 evidence/r85-camera-companion.json 및 evidence/r85-browser-report.json에 남깁니다. 전용 동행 캡처는 실제 native 스냅샷을 별도 캔버스에 그리며 사용자 저장이나 기억을 해제하지 않습니다.

원작의 개 동행은 기존 화면 자료와 native history-actor 경로에서 확인됩니다. 확대 타이밍·배율의 원작 영상 대조는 완료하지 않았으며 이번 카메라는 몽유용 연출입니다. 원작 그림·음원·대사의 완전 복원으로 표시하지 않습니다. 실제 Android 휴대폰의 조작감·발열·프레임 유지와 100개 기억 완주는 아직 확인하지 못했습니다.

APK는 Android 8.0 이상용 몽유 R85 테스트(0.85.0-preview, versionCode 85)입니다. 기존 org.quadrift.mongyu.preview.r82 ID와 같은 서명 키를 유지합니다. 앱 데이터와 저장 진도를 지우지 말고 기존 R82~R84 위에 업데이트 설치하십시오. 실제 결제·광고는 계속 비활성입니다.
