# R94: 외부 파일 없이 플레이 복구

R93은 원작 파일을 직접 실행한다는 목표로 바꾸면서, 사용자가 원본 ZIP/JAR를 보유하지 않으면 게임을 시작할 수 없게 만들었다. 설치 후 플레이할 게임을 요청한 사용자에게 적합하지 않은 변경이었다. R94는 해당 시작 화면과 외부 파일 의존성을 배포 APK에서 제거하고, R92의 몽유 게임을 기본 플레이 경로로 복구한다.

## 사용 방법

R93을 삭제하지 않고 R94 APK를 설치한다. 첫 화면의 ‘꿈속으로’를 누르고 이야기를 진행한 뒤 첫 꿈을 시작한다. 원본 파일 선택·회원가입·네트워크 연결·추가 다운로드가 필요하지 않다. 게임 중 화면을 누르면 점프하며 일시정지 버튼과 Android 뒤로 가기를 사용할 수 있다.

동일한 앱 ID `org.quadrift.mongyu.preview.r82`와 기존 미리보기 인증서, 버전 코드 94를 사용한다. 원래 몽유 진행·옷장·설정을 계속 사용할 수 있게 저장 원점과 네이티브 저장소를 유지한다. R93 내부 원본 파일과 저장은 삭제하지 않지만 이번 기본 게임에서 실행하거나 몽유 진행으로 변환하지 않는다.

## 구현

배포 자산은 검증된 몽유 소스 53개와 CC BY 4.0 음악 18곡을 포함하는 오프라인 HTML 한 개다. 예전의 퇴역 모드·그림과 R93 원본 가져오기 화면/WASM은 이 HTML에 넣지 않는다. Android는 이 HTML만 제공하며 외부 탐색·네트워크·파일 접근을 막는다. HTML의 인라인 코드·스타일·내장 오디오를 실행할 수 있도록 네이티브 CSP도 맞췄다. 외부 스크립트를 허용하는 방식으로 해결하지 않는다.

빌드에서 원본 파일 입력 UI·원본 실행기 참조가 없는지, 자산이 하나뿐이고 지정된 해시와 같은지 검사한다. 웹 빌드는 기존 R92 검사를 위한 기본 경로와 `--release R94` 배포 경로를 구분하며, `scripts/build-playable.py`가 과거 생성 자산을 지운 후 현재 HTML을 복사한다. 이전 저장소·내부 파일을 지우는 코드는 추가하지 않는다.

## 검증과 한계

브라우저에서 4개 화면 크기·40개 실제 UI 상태를 검사했다. 페이지 로드 후 네트워크를 끊은 상태로 정상 버튼 입력을 통해 이야기·게임·음악·일시정지·설정을 확인했고, 원본 파일 입력 없이 전체 화면에서 이동했다. 게임 상태를 주입하지 않았으며 완료된 이야기의 정상 보상만 사용했다.

Android 검사는 실제 R93 소스의 APK를 먼저 설치한 뒤, 같은 임시 QA 인증서의 R94로 업데이트한다. 원본 미선택 상태에서 제목 화면과 실제 게임까지 진행되는지, 기존 네이티브 키 보존·음악 재생·일시정지·앱 복귀·강제 종료 후 재실행·렌더러 복구를 확인한다. [최종 검사](https://github.com/0ssol1620-byte/mongyu/actions/runs/43721995606)가 커밋 `f476e1b7e427e38ea22b10b4852852dad0d8c5f3`에서 통과했다. API35 x86_64/SwiftShader 에뮬레이터와 임시 QA 인증서를 사용했으며, 실제 R93 소스를 기준으로 업데이트했다. 이전 키 보존 검사는 합성 카나리와 불투명한 원본 저널 모양의 탐침을 사용하며, 실제 원작 진행 변환이나 모든 원본 저장 형식을 검증한 것은 아니다.

배포 APK는 이 Actions에서 검사한 unsigned 산출물 자체에 기존 미리보기 인증서로 서명했다. 서명 외 5개 ZIP 항목이 동일하며 HTML 해시·버전·인증서·권한 없음·ZIP 정렬을 확인했다. 최종 서명 APK를 물리 휴대폰에 직접 설치한 검사는 아니다. `evidence/r94-android.json`, `r94-signed-apk.json`, `r94-browser.json`, `r94-web-tests.json`과 실제 에뮬레이터 화면에 근거를 남겼다.

첫 Android 검사에서는 게임 시작까지 통과했으나 Quickstep 런처 ANR이 뒤로 가기 입력을 가로막았다. 실패 화면에서 해당 시스템 창을 확인한 뒤, 명시적으로 식별한 Quickstep 오류만 처리하도록 검사 도구를 수정했다. 게임 ANR이나 임의 오류 창을 닫아 통과시키지 않는다. 이후 전체 검사는 통과했다.

이 버전은 원작의 완전 동일 복구를 완료한 버전이 아니다. R92 기반의 자체 콘텐츠·그림·음악에 남아 있던 품질 차이를 이번 수정으로 모두 해결했다고 주장하지 않는다. 사용자에게 원본 파일을 요구해 플레이를 막았던 회귀를 바로잡는 미리보기다. 기존 게임의 장시간 실제 휴대폰 성능·원작 전체 콘텐츠와의 동등성은 별도 검증이 필요하다. 실제 결제·광고는 없다.
