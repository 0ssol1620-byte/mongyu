# 몽유 R105 UI·로비 명세

방향: **세계 자체가 메뉴다.** 정원 디오라마(Monument Valley·Sky식) 로비에 두툼한 모바일 게임 버튼의 손맛을 더한다. R105 빌드(`MONGYU_UI_EDITION===true`, `<html data-ui-edition="true">`)에서만 켠다. R103·R104의 화면은 바꾸지 않는다.

## 지금 화면의 문제 (실제 화면 6장을 보고 정리)
- 로비: 메인 버튼이 글자("꿈속으로 ▸")뿐이고, 같은 비중의 글자 메뉴 6개가 두 줄로 나열. 아이콘이 유니코드 기호(◇ ✦ ≡ ∞ ✧ ◈). 배경이 절차 생성 성운이라 흔한 배경 화면 같음. "꿈의 길" 입구가 없음.
- 설정: 웹 양식 같음(줄만 있는 행, 기본 슬라이더, 정렬 제각각, 상태를 글자로 표시, 음악 출처 줄이 날것).
- 결과: 점수가 캐릭터와 장애물 위에 겹침. 정보가 가운데 정렬된 글자 더미.
- 이야기·옷장: 같은 문구 15줄 반복, 똑같은 회색 실루엣 격자.

## "AI 티·PPT 티" 목록 (쓰지 않는다)
유니코드 기호 아이콘 · 같은 모양의 알약 버튼 나열 · 모든 것의 가운데 정렬 · 흔한 보라 글로 그라데이션 · 절차 생성 성운 배경 · "라벨 · 값" 형태의 점(·) 구분 · 같은 카드 격자 반복 · 플레이스홀더 문구 반복 · 설명문이 긴 안내

## 디자인 토큰
- 색: 새벽 보라 `#1b1530`~`#3a2c5c`, 금빛 `#ffd98a`, 청백 `#dff2ff`, 분홍 `#ff9ed8`, 위험 산호 `#ff8a73`, 오로라 청록 `#7ff3e1`. 의미 색은 코스와 같게 고정(금 = 탭·수집, 산호 = 위험, 오로라 = 목적지).
- 글자: 시스템 한글 폰트 스택, 최소 14px(보조 설명 12px는 없어도 되는 정보만), 제목 28/32, CTA 20, 라벨 15. 굵기는 두 가지(500/700).
- 간격 8px 단위, 모서리 16/24, 그림자는 부드럽게(색 있는 글로 금지).
- 버튼 3단계: **기본**(금빛, 아래쪽 4px 두꺼운 가장자리로 입체감, 높이 60px, 하단 엄지 영역), **보조**(어두운 유리 + 1px 테두리, 아이콘 + 짧은 라벨), **텍스트**(작은 링크). 눌림: 0.08초 안에 0.96배 + 2px 내려감, 짧은 "톡" 소리, 진동은 약하게.
- 아이콘: 같은 선 굵기(2px, 둥근 끝)로 직접 그린 SVG 세트: 달리기(재생), 지도, 옷장(옷걸이), 이야기(책), 모드(달), 무한(∞), 별, 반짝임, 문, 설정(슬라이더), 닫기, 뒤로, 소리, 진동, 접근성, 공유, 포스터, 영상.
- 움직임: 화면 전환은 오로라 문 와이프(0.4초), 요소는 40ms 간격으로 차례로 등장, 캐릭터 숨쉬기·눈 깜빡임·망토 흔들림, 떠다니는 입자. `reduced`면 전환은 짧은 페이드, 입자는 정지.

## 로비 (390×844 기준)
- **전체 배경 = 직접 구성한 장면(벡터, 캔버스):** 새벽 하늘 그라데이션 2색, 안개 띠 3층(패럴랙스 천천히), 떠 있는 한국 건축 실루엣(기와 처마선, 돌탑, 달항아리 같은 달), 중경에 "꿈의 길"이 계단식 섬으로 이어져 위로 올라가는 모습. 첫 섬 위에 새 캐릭터가 숨쉬며 서 있음.
- **메인 CTA** "달리기": 하단 중앙(화면 높이 약 78%), 폭 70%, 숨쉬는 반짝임. 누르면 꿈의 길 다음 코스(처음이면 코스 1)로 진입.
- **하단 도크:** 아이콘 + 라벨 5개 균등(꿈 지도 · 다른 꿈 · 옷장 · 이야기 · 꿈의 섬). "다른 꿈"은 아래에서 올라오는 시트에 무한 꿈 / 오늘의 도전 / 착시 정원 카드 3장.
- 우상단 설정(아이콘 버튼 48px), 좌상단은 비움. 타이틀 로고 "몽유"는 직접 구성한 레터링.
- 가로 모드(844×390): 장면은 그대로 넓게, CTA와 도크는 오른쪽 열로 이동.

## 설정·일시정지
- 구역으로 묶기: 소리 · 화면 · 접근성 · 정보. 각 구역에 아이콘.
- 켜고 끄는 항목은 **진짜 스위치**(aria-pressed 연동), 슬라이더는 게임 스타일(굵은 트랙, 큰 손잡이), 정렬은 왼쪽 라벨/오른쪽 컨트롤로 통일.
- 음악 출처·이용 조건은 "정보" 안으로 이동하고 날것 줄은 보이지 않게.

## 결과·목록 (2차 작업, 코스 엔진과 합친 뒤)
- 결과: 스테이지가 포스터처럼 보이게 비우고, 점수·별·버튼은 화면 하단 1/3에 고정해서 겹침 없애기.
- 이야기 목록: 잠긴 항목은 숨기고 열린 항목만 삽화 썸네일로. 옷장: 잠긴 옷은 실루엣 하나에 "?" 표시로 줄이고 열린 옷을 앞에.

## 지켜야 할 것
- 모든 새 문구는 `MongyuI18n`(작업 E1)의 키로 연결한다. 한국어 원문은 `docs/R105_VOICE_TONE_KO.md`를 따른다.
- 접근성: 터치 대상 최소 44px, 대비, 색약 모드와 `reduced` 존중.
- 성능: 로비 장면 그리기 프레임당 3ms 이하(데스크톱 Chrome).
