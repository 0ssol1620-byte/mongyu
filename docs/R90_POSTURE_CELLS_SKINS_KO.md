# R90 자세·크기·장애물·맵 스킨 수정

R89에서 원인을 확인하고도 진단으로 멈췄던 문제를 실제 수정했다. 기존 관통 검사를 통과했다는 사실을 자연스러운 동작이나 원작 전체 동일성의 증명으로 취급하지 않는다.

## 달리기와 크기

R89는 두 다리의 총 뼈 길이 25에 비해 골반이 약 19단위 높이였고, 접지 보정이 발목을 2.3단위 더 올렸다. 평지에서도 무릎이 깊게 굽는 원인이었다. R90은 다리 뼈를 각 11단위로 조정하고, 골반이 보폭에 맞춰 올라오는 궤적을 사용한다. 발목의 기본 높이는 -1로 통일해 발이 지면 근처에 닿게 하고, 장애물이 있을 때만 추가로 들어 올린다. 서 있는 자세와 평지의 체중을 받는 중간 자세에서 무릎이 150도 이상 펴지는 것을 별도로 검사한다. 회복 중인 다리, 점프, 모서리 회전까지 항상 곧게 펴는 것은 아니다.

캐릭터의 논리적인 키 42.5와 충돌·점프·입력·난수·점수는 유지한다. 일반 카메라의 짧은 축은 320에서 384단위로 되돌렸다. 인물 키/짧은 화면 축의 명목 비율은 13.28%에서 11.07%가 되며, 확보한 원작 일반 화면의 대략 10~11%와 가까운 구도다. 이 비교는 원작의 모든 카메라·자세에서 동일한 크기를 보장하지 않는다. 전후 배율과 무관하게 몸 중심 추적, 전체 화면 배경, 보스·분할 화면의 경기장 구도를 유지한다.

## 장애물 표현 누락

개인 분석용 KTF 후보의 `box.pzx`는 10×40 인덱스 평면에 10×10 프레임 4개를 담고 있었다. 각 프레임의 기준 오프셋은 -5,-5였다. 모양은 비스듬한 사각형, 마름모, 반대쪽으로 비스듬한 사각형, 축에 나란한 사각형이다. 이 작은 기하학 자료를 대조한 결과 R89에서 같은 벽돌로 처리한 것은 잘못이었다. 후보의 공식 진위나 다른 통신사 버전까지 보증하지는 않는다.

R90은 이동 셀의 실제 프레임 번호에 맞춰 자체 벡터 사각형을 회전시키며 명령의 중심 좌표에 배치한다. 지형용 바닥 왼쪽 기준점을 이동 셀에 재사용하지 않는다. 원래 명령의 알파·등장 위치·프레임 순서를 유지하고, 움직임 줄이기에서는 회전만 고정한다. 원본 픽셀 파일은 배포하지 않는다. 수치 근거는 `evidence/r90-box-frame-audit.json`에 남겼다.

지형 색도 10개 자체 테마의 나머지 연산과 프레임 `%3`에서 벗어나, 100개 수치 팔레트의 지형 색으로 연결했다. 원본 사각형이라는 개념만 같고 모든 종류를 같은 벽돌로 그리던 차이를 줄인다. 모든 보스·효과·무늬의 원본 스프라이트가 복원됐다는 뜻은 아니다.

## 아이템과 수집 기록

[제작자 인터뷰](https://www.gamemeca.com/view.php?gid=65877)는 100개 슬롯과 컬러 스킨을 설명하고, [출시 당시 기사](https://www.gamemeca.com/view.php?gid=66187)는 유료 아이템을 스킨으로 소개한다. 원작 스킨을 현재의 캐릭터 옷장 12종과 같은 것으로 취급하면 안 된다. 기존 문서의 ‘원본 스킨 그림 100종’이라는 표현도 캐릭터 의상 100종으로 읽히지 않게 구분해야 한다. 과거 배포 문서는 당시 기록으로 보존한다.

R90은 검증된 조건을 만족해 획득한 실행의 실제 맵 팔레트를 별도 장부에 기록하고, 기억 모음에서 그 색과 접힌 8×8 패턴을 보여 준다. 과거 기록에 관측한 팔레트가 없으면 임의의 색을 원작 스킨이라고 채우지 않는다. 기존 기억을 정상 재플레이해서 조건을 만족하면 기록할 수 있다. 미해금 항목·자유 플레이·조건 미달 결과로 스킨 기록이나 진행도를 지급하지 않는다. 장부는 수집 결과를 부여하거나 수정하지 않는 시각 기록이다.

이는 몽유의 수집 표현 개선이며 원작의 전체 스킨 시스템을 완전히 복원했다는 뜻은 아니다. 필드에서 먹는 강화 아이템이나 특정 아이템과 확대의 관계는 확인되지 않았으므로 이번 수정에 새 효과를 지어 넣지 않았다.

## 검증

`r90-posture-skins.test.cjs`는 서기·지지 자세, 보폭·고정 뼈 길이, 화면 비율, 100개 팔레트, 중심 기준의 회전 프레임, 정당한 수집 기록·잠금·손상 저장·저장 실패와 64개 패턴 셀을 검사한다. 기존 카메라·입력·접지·저장·음악 검사를 유지한다.

`audit-r90-filled-contact.cjs`는 74개 격리 진입, 최대 220 업데이트, 7 업데이트마다 정상 액션으로 접지 1,867개·중간 코너 365개를 검사한다. 실제 다리 채움 픽셀을 지형 내부 11×11 영역과 비교한다. `verify-r90-art-contact.cjs`는 별도로 15개 실제 화면을 확인한다. 모든 입력·몸 전체·모든 기기의 무관통이나 100개 연속 완주 인증은 아니다.

`verify-r90-skin-flow.cjs`는 실제 UI에서 이야기를 진행하고, 정상 입력과 시간 진행으로 첫 물리 스테이지의 정당한 결과를 얻는다. 수집 화면에서 실제 팔레트 표시, 미해금 항목의 미표시, 재시작 후 기록 유지를 확인한다. 위치·체력·점수·진행도·영수증 주입은 없다. Android 검사에도 정상 플레이 수집과 APK 업데이트 후 장부 보존 검사를 추가했다. 최종 설치·서명 결과는 아래에 기록한다.

## 최종 결과와 배포

[Android 검사](https://github.com/0ssol1620-byte/mongyu/actions/runs/43697029576)가 런타임 커밋 `6db586506fb419af493f38fd64fe603082dd4d86`에서 통과했다. 웹 검사는 174개 중 173개 통과·외부 어댑터 1개 제외·실패 0개이며, 최종 Android 실행에서는 동일 웹 소스 해시의 통과 캐시를 재사용하고 HTML을 다시 대조했다. 실제 전체 웹 검사 실행은 [이 실행의 웹 단계](https://github.com/0ssol1620-byte/mongyu/actions/runs/43696815592)에 있다. Android 래퍼 검사 5개도 별도 통과했다.

Android 15 / AOSP WebView 124에서 설치·전체 화면·입력·뒤로 가기·백그라운드 복귀·저장 업데이트·렌더러 종료 복구, 15개 실제 렌더링 장면, 정상 입력의 스킨 획득·표시와 업데이트 뒤 장부 보존을 확인했다. 첫 Android 검사에서는 검사 코드가 실제 격리 접두어를 빠뜨린 키를 읽는 오류가 있었다. 실제 저장 위치로 검사를 정정한 뒤 전체 검사를 통과했다. 게임 진행도를 주입하거나 검사 항목을 없애서 통과시키지 않았다.

정상 UI 수집 검사는 415 업데이트의 정당한 클리어 결과를 사용했다. 별도 12초 표시 녹화는 720개 프레임, 세 지면 방향, 양쪽 진행 방향, 220 업데이트와 2목숨을 기록했다. `r90-posture-metrics.json`은 이전·새 리그의 서기와 지지 자세, 카메라 배율을 수치로 남긴다. [이전 모습](../evidence/r90-character-before.png) · [새 모습](../evidence/r90-character-after.png) · [움직임 표본](../evidence/r90-motion-contact-sheet.png) · [획득한 맵 기록](../evidence/r90-android-earned-skin.png).

같은 Chromium·390×844·DPR 상한 1.5·CPU 4배 제한에서 순서대로 600 RAF 프레임을 재측정했다. 프레임 p95는 R89 34.4ms, R90 37.4ms, 최대는 122.1ms·119.9ms였다. 명시적 그리기 120회 p95는 R90 2.6ms였다. R90의 지연 개선을 주장하지 않으며 긴 프레임이 남아 있다. 원자료는 `r90-sustained.json`, `r90-r89-baseline.json`, `r90-browser-report.json`에 있다. 실제 휴대폰의 장시간 성능·청음은 이 검사와 별개다.

배포 APK는 검사한 unsigned 파일에 기존 인증서로 서명했다. 서명 메타데이터를 제외한 모든 ZIP 항목이 검사 파일과 같은지 확인했다. APK SHA-256은 `1ba884137a92488cc1f9f0a8498549358eb50504e2925ca758fc97151c952ee9`이다. QA 업데이트는 현재 코드로 만든 versionCode 89/90과 일회용 CI 키를 사용하며, 최종 서명 APK 자체의 실기기 설치와 구분한다. [R90 APK·소스](https://github.com/0ssol1620-byte/mongyu/releases/tag/r90-preview). 기존 앱을 지우지 않고 업데이트할 수 있다. 원작 전체 동등성·모든 필드 아이템 복원·100개 연속 완주·실제 광고와 결제·스토어 출시 완료를 뜻하지 않는다.
