# R91 보행 연결과 사이키델릭 배경

R90은 골반 높이와 무릎 각도를 고쳤지만, 팔의 뒤쪽 스윙과 뒤꿈치 회수, 몸통의 연결, 착지 상태 전환까지 자연스럽게 만든 것은 아니었다. 이번 수정은 그 동작을 실제 다시 만들고, 기본 플레이에서 약했던 추가 배경 연출과 작동하지 않던 강도 설정을 연결한다.

## 캐릭터

- 뒤로 가는 팔의 팔꿈치가 계속 접혀 손이 몸 앞에 남던 관계를 수정했다. 뒤쪽 팔은 열리고 앞쪽 팔은 접히며 반대 다리와 교차한다. 팔 길이는 상완 8.5·전완 7.5로 고정한다.
- 한 주기를 이동 거리 42단위로 구성한다. 지지 구간에서는 발의 뒤쪽 속도가 실제 이동 거리와 맞고, 발뒤꿈치로 디디기와 발끝으로 밀어내기가 이어진다. 회수 구간은 뒤꿈치를 골반 뒤로 들어 올린 다음 앞으로 가져오는 연속 궤적이다. 단순한 낮은 반원 왕복을 대체했다.
- 골반의 하중 변화에 몸통과 머리도 함께 움직여 몸통이 반복적으로 접혔다 펴지는 인상을 줄인다. 팔다리의 윤곽과 머리 비율을 더 가늘게 조정하고, 무릎의 시각적 과신전을 제한한다. 원작 스프라이트의 픽셀 재현은 아니다.
- 낮은 이륙·착지 높이에서는 지상 자세와 공중 자세를 점진적으로 섞는다. 착지 시 이전 점프 진행률에서 0으로 거꾸로 보간하던 문제를 수정했다. 벽 동작은 실제 표시 중인 분수 프레임을 읽는다.
- 움직임 줄임에서는 배경과 시간 기반 장식을 정지시키면서, 이동에 필요한 거리 기반 보행·개 동행과 위치 보간을 유지한다. 멈춘 팔다리로 화면을 미끄러져 가는 처리를 피한다. 기존 분석 도구의 정확한 스냅샷 옵션은 유지한다.

캐릭터의 논리적인 키 42.5와 카메라의 짧은 축 384, 몸 중심 추적은 유지한다. 입력·점프 궤적·충돌·체력·점수·진행·난수를 바꾸지 않는다. 보스·분할 화면의 구도도 유지한다.

## 추가 배경 연출

기획 방향은 [기존 원작·애니메이션 조사](R89_ART_SOUND_RESEARCH_KO.md)에 연결된다. 추가 배경은 자체 연출이며 원작 전체 화면 효과를 복원했다는 뜻은 아니다.

원래 엔진의 배경 위에 꼭짓점을 공유하는 연속 모자이크를 그린다. 맵 성격에 따라 흐르는 격자, 대칭 접힘, 소용돌이, 느린 팽창이 달라지고, 겹겹의 사각 선이 이어진다. 100개 수치 팔레트의 배경·강조 색을 사용한다. 서로 떨어진 장식 카드를 띄우는 방식은 사용하지 않는다.

고요·균형·강렬 설정을 native 플레이의 실제 렌더러로 전달한다. 강도에 따라 색면의 대비, 격자 밀도와 사각 겹의 수가 달라진다. 동적 셀은 최대 128개, 사각 겹은 최대 12개이며 공유 좌표 버퍼를 재사용한다. 느린 호흡은 곡의 BPM을 참고하지만, 음원 재생 위치와 정확히 박자를 맞췄다는 주장은 하지 않는다.

캐릭터 주변은 추가 색면과 선을 비워 실루엣을 읽을 수 있게 한다. 실제 지형과 장애물은 배경 위에 원래 위치·불투명도로 그린다. 배경에는 부드러운 표시 시계를 사용하고, 일시정지에서는 마지막 시계를 유지한다. 움직임 줄임에서는 추가 배경의 시간 변화와 변형 강조를 정지한다.

## 검증 방법

`r91-motion-field.test.cjs`는 발 접촉과 회수 궤적의 연결, 뒤쪽 손 위치, 팔·다리의 고정 길이, 몸통 길이 변화, 낮은 이륙·착지의 연속성, 착지 진행률과 벽 분수 프레임, 필수 보행과 장식의 움직임 줄임 구분, 강도·예산·일시정지 전달을 검사한다.

`audit-r91-filled-contact.cjs`는 기존과 같은 74개 격리 진입에서 접지 1,867개와 중간 코너 365개의 실제 다리 채움 픽셀을 검사한다. `verify-r91-art-contact.cjs`는 15개 실제 화면을 확인한다. 모든 입력·공중 자세·몸 전체의 무관통을 증명하는 검사는 아니다.

`verify-r91-field.cjs`는 화면 네 크기, 강도 세 단계, 시간 네 위치, 중앙·비중앙 초점의 96개 실제 배경 래스터에서 초점 반경 6%의 투명 영역을 확인한다. 정상 입력으로 도달한 여섯 전체 화면도 캡처한다. 특정 시점의 가독성 검사가 모든 사용자·모든 장면의 가독성을 보증하지는 않는다.

Android에는 강도 제어의 세 단계 순환과 설정 보존 검사를 추가했다. 기존 설치·입력·전체 화면·복귀·업데이트 저장·렌더러 복구·15개 렌더링 장면·정상 획득 맵 스킨 보존 검사도 유지한다. 최종 결과와 성능·서명 근거는 아래에 기록한다.


## 화면·동작과 성능 근거

[이전 보행](../evidence/r91-character-before.png)과 [변경한 보행·공중 자세](../evidence/r91-character-after.png), [12초 화면 표본](../evidence/r91-motion-contact-sheet.png)을 비교할 수 있다. 영상은 격리된 12번 구간에서 정상 입력으로 이동한 브라우저 Canvas 캡처다. 713개 표시 프레임, 219개 native 업데이트에서 세 면과 양방향을 거쳤다. 휴대폰 실기 영상 또는 전체 게임 완주 영상은 아니다.

[전체 웹 검사](../evidence/r91-web-tests-summary.json)는 181개 중 180개 통과·1개 건너뜀·실패 0개다. 최초 Android 실행은 긴 설정 목록의 닫기 버튼을 화면 밖 좌표로 누르던 검사 도구 문제로 실패했다. 버튼을 실제 보이는 위치까지 스크롤한 뒤 터치하고 설정이 닫혔는지 확인하도록 수정했다. 로컬 브라우저의 390×844·320×568·844×390 화면에서 세 강도 순환과 일시정지 유지도 확인했다.

동일 호스트·Chromium·화면에서 CPU를 4배 느리게 제한하고 일반 RAF 600개를 순차 측정했다. R90→R91의 프레임 간격 중앙값은 14.3→17.9ms, p95는 38.0→35.6ms, 최댓값은 110.2→71.7ms였다. 시뮬레이션 p95는 23.8→18.4ms였다. 장식 증가에 따른 그리기 비용이 있으며, 이 한 번의 결과로 성능이 전반적으로 좋아졌다고 단정하지 않는다. R91에도 50ms 이상의 긴 작업 3개와 71.7ms 프레임이 남았다. 실제 저사양 Android 기기의 장시간 발열·프레임 검증은 남아 있다. [R91 측정](../evidence/r91-sustained.json)과 [R90 비교 측정](../evidence/r91-r90-baseline.json)을 함께 제공한다.

추가 배경 강도는 일시정지 → 설정 → 꿈의 강도에서 선택한다. 움직임 줄임을 켜면 배경은 정지하지만 보행과 캐릭터 위치 이동은 계속 표시한다. 원작 그림·음원·대사 전체 복원, 미확인 필드 아이템과 줌의 관계, 100구간 연속 완주, 실제 결제·광고 출시 검증은 이번 결과로 확인한 사항이 아니다.

현재 Android wrapper 파일 `android/tests/r82-wrapper.test.cjs`는 5개 모두 통과했다. Android 폴더의 과거 테스트까지 일괄 실행한 별도 결과는 43개 중 6개 통과·37개 실패다. 과거 R31 패키지·라벨을 전제하는 검사와 `structuredClone`을 제공하지 않는 예전 VM fixture가 현재 R91 자산을 읽기 때문이다. 따라서 Android 폴더 전체 테스트가 통과했다고 표시하지 않는다. 실제 설치 검사는 별도 Actions 결과로 구분한다.


## Android 설치 결과와 배포 파일

[Android Actions 43705266644](https://github.com/0ssol1620-byte/mongyu/actions/runs/43705266644)는 `c8c2533ade16060a2de41c75d8d0f920d885ce79`에서 통과했다. 실제 설치된 API 35 AOSP 에뮬레이터·WebView 124에서 전체 화면, 입력, 뒤로가기 일시정지, 복귀 후 명시적 재개, 세 강도 제어, 15개 렌더링 장면, 정상 입력으로 얻은 맵 스킨, 업데이트 저장, 제한된 렌더러 복구와 사용자 재시도를 확인했다. [전체 결과](../evidence/r91-android-device.json)를 제공한다. 에뮬레이터의 움직임 줄임 기본값이 켜져 있는 상태에서도 검사를 통과했다.

업데이트 검사는 같은 현재 콘텐츠를 담은 합성 versionCode 90→91 QA 패키지를 임시 CI 인증서로 설치한다. 과거 공개 R90 APK에서 직접 업데이트한 실기 검사는 아니다. 배포 APK는 검사를 통과한 unsigned 파일을 기존 미리보기 인증서로 서명했으며, 서명 외 5개 ZIP 항목이 모두 바이트 단위로 일치한다. 이 최종 서명 파일 자체를 다시 기기에 설치한 것은 아니다.

[R91 서명·파일 근거](../evidence/r91-signed-apk.json): APK 8,221,212바이트, SHA-256 `ec2e171b0d673ee63e8c2fad268244316013af3a2b93926d001c781ec6cfc9ea`. 앱 ID `org.quadrift.mongyu.preview.r82`, versionCode 91, Android 8.0 이상·target API 36, 추가 권한 없음. 기존 앱을 지우지 않고 업데이트할 수 있는 동일 ID·인증서다. 실제 기존 기기의 저장 보존을 검증했다는 의미는 아니다.
