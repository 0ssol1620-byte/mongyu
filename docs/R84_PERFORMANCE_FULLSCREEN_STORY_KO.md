# R84 렉·전체화면·스토리 수정

사용자가 R83 Android에서 다시 보고한 지연, 모서리의 멈춤 느낌, 중앙에 작게 놓인 첫 구간과 스토리/대사 표시를 수정했다. 설치 ID와 서명은 R82/R83 테스트 채널을 유지하고 versionCode를 84로 올렸다. 실제 휴대폰에서의 확인 결과는 아니다.

## 지연 원인과 변경

R83의 Canvas 렌더링은 가벼워졌지만 native 시뮬레이션이 한 번 진행될 때 여러 중간 스냅샷을 브라우저 structuredClone 직렬화로 반복 복사했다. 이 계산은 메인 스레드에서 실행돼 그림 그리기가 짧아도 프레임을 지연시킬 수 있었다.

R84는 엔진이 소유한 plain object/array 스냅샷에 전용 복사기를 사용한다. 공유 참조·순환·배열 구멍·열거 가능한 필드를 보존하고 특수 객체/transfer 옵션은 플랫폼 함수로 돌려보낸다. 전역 structuredClone은 덮어쓰지 않는다. native-kernels.js와 native-restoration-run.js의 스코프에 복사기 바인딩 한 줄만 추가했다. 이 줄을 제외한 본문은 R79 기준 해시와 일치하는지 검사한다. 복사기는 state-clone.js로 분리돼 있다.

74개 물리 슬롯에서 같은 초기 상태와 입력으로 각각 16단계를 진행해 플랫폼 복사 경로와 최적화 경로의 전체 nativeFrame·난수·trace·effects·이벤트·결과가 일치함을 확인했다. 기존 74개 슬롯 12단계 회귀 검사도 유지한다. 이는 원작 실기기 동등성이나 전체 구간 완주 검사가 아니다.

## 전체화면과 모서리

이전에는 작은/마스크 경기장에서 전체 방을 정사각형으로 맞추며 세로 공간이 많이 남았다. 일반·마스크 경로를 화면 비율에 맞춘 cover 카메라로 바꾸고 인물을 따라가도록 했다. 좌표를 가로/세로로 다르게 늘리지 않아 캐릭터와 셀의 비율은 유지한다. 보스는 공격 영역을 읽을 수 있도록 전체 경기장을 유지한다.

인물 위치와 회전은 이미 네이티브 프레임 사이를 보간하고 있으므로 별도의 카메라 지연을 제거했다. 회전 각도마다 안전한 화면 위치를 계산한다. 사각 화면의 대각선을 법선에 투영하면 회전 중 인물이 바깥으로 밀릴 수 있어 축별 화면 위치를 사용한다. 다섯 화면 크기의 모든 1도 간격에서 발 위치가 안전한 영역에 남는지 검사했다. 실제 판정 좌표·지형은 변경하지 않는다.

첫 달리기는 이전처럼 화면 가운데 정사각형으로 맞추지 않고, 발판과 진행 방향이 화면을 채우도록 배치한다. Canvas 및 Android WebView의 전체 크기/몰입 모드는 그대로 유지한다. 모든 방의 모든 벽이 동시에 보인다는 의미는 아니다.

## 이야기와 대사

원작에는 그리움과 새로운 만남, 이별로 이어지는 이야기가 있다. 기존 R82 검토에 링크한 제작자 글이 근거다. 다만 현재 소스의 문장은 원작 대사 원문이 아니라 몽유용 각색이다.

이번에는 독백/대화에 화자 이름과 말풍선을 붙이고 밝은 장면 배경에서 인물을 읽을 수 있게 했다. 첫 독백도 짧은 직접 발화로 다듬었다. 제목의 이야기 메뉴에서 만난 장면을 다시 볼 수 있으며 잠긴 장면은 열리지 않는다. 같은 이야기를 다시 읽어도 기억을 중복 지급하지 않는다. 이야기 메뉴에 각색임을 표시한다. 엔딩의 번호만 바꾼 반복 문장은 제거했다. native 커서·페이지 수·완료 조건은 유지했다.

## 확인 범위

- 웹 전체 127개 검사: 126 통과, 실패 0, 배포하지 않는 외부 어댑터 1개 생략.
- Android 콜백 VM 검사 5개 통과.
- 새 복사 경로와 기존 경로의 74개 물리 슬롯 비교 통과.
- 화면 채움, 회전 중 화면 이탈 방지, 잠긴 스토리 방어, 이야기 재생/저장/중복 보상 방어 검사 통과.
- Chromium에서 부팅→옷장 저장 복구→이야기→달리기→일시정지/재개, 네 화면 크기와 오프라인 부팅을 확인했다. 별도 이야기 메뉴·키보드 포커스·재시작 뒤 이야기 재생도 확인했다.
- 공식 SDK 36/JDK 21로 APK를 빌드하고 서명 v2/v3, 16KB 정렬, ZIP, 최종 R84 HTML 동일성 및 R83과 같은 서명 인증서임을 확인했다.

성능 수치는 evidence/r84-performance-story.json을 따른다. 같은 390×844/DPR2, CPU 4배 감속, 120개 화면 주기에 실제 RAF/tick 외 draw 한 번을 추가한 스트레스 검사다. 반복 편차가 있고 Android FPS 측정은 아니다. 실제 휴대폰의 장시간 프레임·발열과 모든 구간의 정상 입력 완주는 여전히 미검증이다. 원작의 그림·음원·대사 전체 원문 복원이나 상용 출시 완료를 주장하지 않는다.
