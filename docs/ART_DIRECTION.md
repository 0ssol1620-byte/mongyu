# 아트 방향과 자산 출처

## 게임 세계가 먼저

- 사각 방, 실제 경로, 작은 사람형 배우, 지지대와 출구가 주 화면을 구성합니다. 설명 카드가 플레이를 덮지 않도록 합니다.
- 성공·실패·정지는 해당 실제 세계의 상태로 표현합니다. 완료하지 않은 곁길이나 장면을 완료한 것처럼 보이면 안 됩니다.
- 말풍선은 인물 머리에 연결하는 짧은 1–2줄 표현입니다. 정확한 장문 결과와 접근성 상태는 기존 DOM 경로로 보존합니다.
- 동행 사건은 발판과 연결 경로, 답신 사건은 신호와 문 잠금, 낮·밤 사건은 실제 승강대·턱·문 위치의 인과로 표현합니다.
- reduced-motion에서는 같은 의미를 정적 상태로 전달합니다. 장식이 충돌·이동·보상 판정을 바꾸지 않습니다.

이 문서는 기존 디자인 의도를 요약한 것이며 새로운 시각 구현이나 실제 브라우저 접근성 인증을 주장하지 않습니다. 과거 QA 스크린샷과 원본 비교 그림은 이 저장소에 포함하지 않았습니다.

## 포함된 자산

`web/assets/r10/manifest.json`은 세 WebP 배경(`tidal`, `mirror`, `eclipse`)의 바이트 수, SHA-256 및 제작 출처 기록입니다. 기록상 이 작업용 AI 생성 배경이며 참조 게임에서 추출한 자산이 아닙니다. 원래 PNG의 이름/해시는 출처 기록으로만 남아 있고 빌드에는 필요하지 않습니다. 배경은 분위기용이며 충돌 형상은 엔진이 소유합니다.

배우·사각 세계·신호·문 등은 Canvas 코드로 그립니다. 런타임은 기기 시스템 글꼴을 사용하며 글꼴 파일을 배포하지 않습니다. 소리는 Web Audio 합성입니다. 위 출처 기록은 독립적인 권리 보증이나 상업 출시용 최종 지식재산 검토를 대신하지 않습니다.
