# R31: 실제로 건넌 밤길만 회고

낮·밤 곁길을 실제로 빠져나왔을 때만 활성 여행의 `narrative.dayNightCrossed`가 참이 됩니다. 초대 수락, 낮·밤 전환, 문 열기, 중간 취소는 완료가 아닙니다. 출구 상태·위치·높이·고정 턱 지지·밤의 열린 문을 함께 확인합니다.

완료 사실은 휘발성이며 저장·점수·기억 자격·진행 분기에 넣지 않습니다. 자동 마지막 방 진입과 동일 활성 마지막 방 재도전에서는 유지하지만 홈·새 달리기·직접 마지막 방·다른 모드는 기존 초기화 경계를 따릅니다.

`origin-finale`의 `clear`에서만 짧은 머리 말풍선과 기존 접근성 DOM에 회고합니다. fail/pause에는 결말 회고를 표시하지 않습니다. 새로운 퍼즐이나 물리 변경은 아닙니다.

`web/tests/r31-day-night-ending.test.cjs`의 14개 사례를 소스와 실제 인라인 HTML로 각각 검사합니다. Android 테스트는 동일 HTML과 Java의 native back/onPause 표현을 VM에서 검사합니다. 실제 브라우저나 Android 스케줄링을 대신하는 검사는 아닙니다.
