# R92: 남은 실험 모드 정리와 원작 표현 재조사

사용자가 첨부한 두 화면은 현재 native 수집 여정과 다른 과거 캠페인·연습 화면이다. ‘다른 꿈’ 메뉴가 메인·일시정지·설정에서 계속 열려 있어 예전 HUD·카메라·그림·캐릭터로 이동할 수 있었다. R91에서 이 경로를 제품 흐름으로 남긴 것은 잘못이었다.

R92 배포 HTML은 `data-edition=mongyu`로 여정을 하나로 제한한다. 실험 모드 메뉴·연습·옛 기억과 지도 진입을 제거하고, 실행 함수도 상태를 바꾸기 전에 거부한다. CSS로 첫 표시부터 숨기고 DOM에서도 숨김·inert를 적용하며 이벤트 연결을 해제한다. 옛 그림 자산은 `MONGYU_EMBEDDED_IMAGES`에 넣지 않는다. 소스의 과거 시뮬레이션·테스트와 저장 키는 기록·호환성 때문에 보존하지만 플레이어가 선택할 수 있는 모드로 제공하지 않는다. 기존 저장은 삭제하거나 새 여정으로 변조하지 않는다.

## 이번에 직접 확인한 원작 근거

공개 보관 자료의 KTF V1.0.1 후보를 [wie](https://github.com/Jun025/wie) 웹 엔진으로 개인 분석 경로에서 실행했다. [서비스의 지원 기록](https://featurephone.otterpebble.com/support/8c8b11508cf5)과 같은 계열이며 엔진 핀은 `1ca15ebf5a3ebc691a680a7854e99a32e75d46f4`, WASM SHA-256은 `a4a32d289c2281239d2d4e9c00c065d10203fe151969a6f324761e4e3a38ecdf`다. 파일은 로컬 루프백 서버와 격리된 Chromium 안에서만 열었다. 원작 파일·음악·화면·대사는 배포하지 않는다.

후보 JAR의 해시는 기존 조사와 같은 `aeadd87840c7b3f1f06548489406dbc0bf833b41de9cdfa3eaf741e832a213c2`다. 공식 배포본이라는 인증은 없다. 기본 보관 ZIP에는 이미 10/100인 저장 기록이 있어, 별도 실행에서는 그 저장 파일만 제외해 첫 안내·첫 이야기 두 페이지·수집판 전환을 정상 입력으로 확인했다. 전체 100개를 새로 완주한 검사가 아니다.

## 녹음곡 교체와 표시

[Eric Skiff / Resistor Anthems](https://ericskiff.com/music/)는 제작자 페이지가 제품 사용과 CC BY 4.0 출처 표시 조건을 명시한다. 18개의 서로 다른 녹음을 사용한다. 맵 10종은 Chibi Ninja·A Night Of Dizzy Spells·Underclocked·All of Us·Come and Find Me·Searching·Ascending·Arpanauts·Digital Native·Jumpshot이다. 보스 4종, 별도 메뉴/수집 곡, 서로 다른 이야기 세 역할도 연결한다. 타이틀과 마지막 이야기 역할은 Prologue를 공유한다. 맵 배치는 몽유의 편집 판단이며 원작 곡 배치의 복원으로 표시하지 않는다.

각 녹음은 최대 64초를 발췌하고 음량 정리, 시작·끝 페이드와 MP3 변환을 적용했다. 정확한 음악 마디 단위의 무봉합 루프나 박자 동기화를 주장하지 않는다. 원본 다운로드 URL·원본/편집 파일 해시·편집 방법을 manifest와 MUSIC-CREDITS.txt에 기록하고 게임 설정에도 작곡가·곡명·라이선스·변경 사항을 표시한다. 원본 음원을 그대로 사용했다거나 몽유 자체 작곡이라고 표시하던 문구도 교체했다. 복원 도구는 원본 해시를 확인하며 누락 시 예전 합성곡으로 조용히 대체하지 않는다.

[음량·디코딩 검사](../evidence/r92-audio-decode.json)는 18곡 모두 스테레오, -20~-16 LUFS, true peak -1 dBFS 이하를 확인한다. 주관적인 음악 품질·실제 휴대폰 스피커 청음 검수의 대체는 아니다.

## 검증과 남은 범위

제품 브라우저 검사는 네 화면 크기에서 실제 메뉴·옷장·설정·이야기·수집판·플레이·일시정지·복귀·재실행 40개 상태를 확인한다. 잠긴 진행이나 체력·좌표를 주입하지 않는다. 실제 녹음 재생과 이야기→맵 곡 전환, 이전 모드 함수 호출이 native 상태를 바꾸지 않는 것도 검사한다.

숫자 카메라 검사에 남아 있던 ‘머리는 타원이어야 한다’는 구현 가정을 실제 채워진 머리 윤곽을 읽도록 바꿨다. 화면 중앙 추적·크기·모든 방향의 머리가 지형 밖을 향하는 조건은 유지한다. native 시뮬레이션 소스의 기존 해시 보호도 유지한다. 원작 포즈의 미학적 일치는 숫자 검사만으로 보증하지 않는다.

최종 Android·서명·배포 결과는 아래에 기록한다. 물리 휴대폰의 장시간 성능·발열·청음, 원작 전체 대조, 실제 결제·광고 운영과 스토어 출시 검증은 남아 있다.


실제 실행을 확인할 수 있는 [원작 실행 메타데이터](../evidence/r92-original-execution.json)에는 엔진 핀·해시, 개인 분석 화면의 해시, 음악 메시지 개수·채널 수·Yamaha 설정 이벤트 수만 담았다. 원작 그림이나 음표 데이터는 담지 않았다. 해당 에뮬레이터와 현대 사운드폰트로 재생한 결과는 옛 휴대폰의 음색과 동일하다는 인증이 아니다.

브라우저 비교는 같은 호스트에서 순차적으로 CPU 4배 제한·RAF 600개·같은 정상 입력 정책으로 진행했다. 실제 측정 창은 시작 UI 직후로 카운트다운도 포함하며, 기존 도구의 ‘post-countdown’ 설명을 그대로 받아들이면 안 된다. R91→R92 프레임 간격 중앙값 17.9→18.7ms, p95 40.4→40.1ms, 최대 100.9→92.4ms였다. 시뮬레이션 p95는 19.4→18.9ms다. 차이가 작고 긴 프레임도 남아 있어 성능 개선·무지연·실기기 성능을 주장하지 않는다. [R91 비교](../evidence/r92-r91-baseline.json), [R92 측정](../evidence/r92-sustained.json).

[소리가 포함된 12초 브라우저 기록](../evidence/r92-play-with-sound.json)은 기본 여정의 실제 UI로 시작한 뒤 Space 입력 24회와 실제 시간만 사용한다. 210개 업데이트, 플레이 상태·체력 3개가 유지됐으며 실제 앱 오디오 그래프의 Eric Skiff 녹음과 효과음을 함께 캡처했다. 실제 Android 휴대폰 녹화는 아니다. 영상에도 Eric Skiff / Resistor Anthems / CC BY 4.0이 적용된다.


## 최종 빌드와 Android 결과

[Actions 43710355665](https://github.com/0ssol1620-byte/mongyu/actions/runs/43710355665)는 `c281245c0d1e103ec6267b49927712bd8ed55921`에서 통과했다. 웹 183개 중 182개 통과·1개 제외·실패 0개이며 현재 Android wrapper 파일의 5개 검사도 통과했다. [검사 요약](../evidence/r92-web-tests-summary.json).

실제 설치한 API 35 AOSP 에뮬레이터·WebView 124에서 13개 검사: 이전 모드 메뉴·그림 자산 제외와 18곡 메타데이터, 전체 화면, 실제 Canvas 출력, 실제 녹음곡 시작, 뒤로가기 일시정지, 앱 복귀, 강도 세 단계, 실제 렌더링 15개 장면, 정상 입력으로 얻은 맵 스킨, 업데이트 후 저장 유지, 첫 렌더러 복구, 반복 종료 후 재시도 대기와 사용자 재시도를 확인했다. JavaScript 예외는 0개다. [설치 결과](../evidence/r92-android-device.json).

업데이트 검사는 같은 현재 콘텐츠에 versionCode 91/92를 부여한 합성 QA 패키지와 임시 CI 인증서를 사용한다. 공개 R91을 실제 휴대폰에서 업데이트한 검사는 아니다. 배포 APK는 해당 unsigned 페이로드를 기존 미리보기 인증서로 서명했으며 서명 외 5개 ZIP 항목이 모두 동일하다. 최종 서명 APK 자체를 다시 실기기에 설치하지는 않았다.

[R92 서명 검사](../evidence/r92-signed-apk.json): 14,328,348바이트, SHA-256 `b539b0f8c8655bca2ed92c792636b127c76ae4d5610a4400b5102c1f3398b6e6`. 앱 ID와 인증서는 기존 테스트와 같고 versionCode 92, Android 8.0 이상, target API 36, 추가 권한 없음이다. 내장 HTML SHA-256은 `bf1ead4e0953e31d92c34966144c35dd5deb1b1624d67a26379213bc8077a6d5`로 검사한 소스와 일치한다.
